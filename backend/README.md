# Backend (BFF / REST API)

Сюда будет перенесён код Node.js + Express: `index.js`, `queries.js`, маршруты, подключение к БД.

**Целевая структура внутри backend:**

- `index.js` — точка входа, подключение к БД, подключение маршрутов
- `config/` — настройки (pool, env)
- `routes/` — эндпоинты по доменам (systems, refs, technologies, …)
- `services/` — бизнес-логика при необходимости
- `db/` или слой запросов — вызовы к PostgreSQL (аналог текущего `queries.js`)
- `views/` — EJS-шаблоны, если остаются на backend
- `public/` — статика (например echarts)

Пока код лежит в корне репозитория; после переноса здесь будет вся серверная часть архитектурного репозитория.
