# Встраивание `AnalyzerGraph` (issue #33)

## Назначение

Один компонент `frontend-v3/src/components/AnalyzerGraph.vue` используется в **анализаторе зависимостей** и на **вкладках «Связи»** форм. Режим задаётся пропом **`variant`**.

## Пропсы

| Проп | Описание |
|------|----------|
| `variant` | `'analyzer'` (по умолчанию) — полный UI; `'embed'` — без левой панели и экспорта SVG/PNG, узлы не перетаскиваются. |
| `showToolbar` | Явно показать/скрыть панель (как слева, так и кнопки экспорта). Если не задано: при `embed` — скрыто, иначе — показано. |
| `showPalette` | Палитра свойств (issue #116). Если не задано — показывается вместе с полной панелью (`analyzer`); во встройке палитры нет. |
| `contextMenu` | `'full'` \| `'minimal'` \| `'off'`. Если не задано: `embed` → `'minimal'` (только «Просмотр»), иначе `'full'`. |
| `graphHeight` | Fallback-высота области графа (например `780px`). На вкладках карточки по умолчанию работает **авто-высота**: сплит занимает место до липкой панели сохранения (`SaveBar`), а граф растягивается по этой высоте (`100%`). Авто-высота отключается на узких экранах (≤1024px) и при `auto-height="false"`. |
| `showExportButtons` | Кнопки **SVG** / **PNG**. Если не задано — показываются только вместе с полной панелью (`showToolbar`). На формах задайте `true`, чтобы оставить экспорт без левой панели раскладок. |
| `centerNodeId` | `nodeId` центра для первичной раскладки «звезда» при появлении узлов (удобно, когда известен корень, напр. `gap:12`). |

Остальные пропсы (`nodes`, `edges`, `relations`, `relationTypes`, `showCascadeToggle`, …) без изменений.

## Вписывание в область графа

- Первичное построение и явная смена топологии: `applyLayout` → `fitToContents({ reset: true })`.
  Fit библиотеки `v-network-graph` **асинхронный** — обёртка дожидается его завершения (иначе
  viewBox-правки идут по устаревшему состоянию и отменяют fit), затем применяет «минимальный
  экстент» `GRAPH_VIEWBOX_MIN`, чтобы 1–2 узла не выглядели гигантскими.
- Раскрытие связей: `fitToContents()` без `reset` — правило «только уменьшать масштаб», и только когда
  в графе появились **новые** узлы.
- ПКМ, выделение, скрытие объектов/связей и изменение размера области в анализаторе **не меняют**
  вьюпорт: после первичного отображения масштаб и фокус — на усмотрение пользователя (issue #134).
  Во встройке (`variant="embed"`) вписывание при изменении размера области сохраняется (вкладки форм, issue #125).
- `autoPanAndZoomOnLoad` в конфиге не используется: библиотека не должна перевписывать граф при
  пересоздании конфигов (зум меняет `fontSize`/`margin`).

## Выделение и палитра (issue #116)

- ЛКМ/ПКМ по узлу или связи выделяет объект: узел — рамка, связь — красная линия; одновременно активен
  только один объект (узлы и связи ведут отдельные наборы, «чужой» очищается в `selectOnly`).
- В анализаторе слева показывается **палитра свойств** (`AnalyzerPalette.vue`): блок «Настройки»
  (каскад, легенда, связи, топология) и блок «Свойства» — read-only key-value выбранного узла или связи.
- **Легенда** и **«Связи»** — плавающие панели на графе (легенда слева снизу, связи справа снизу) с шапкой
  и крестиком: закрытие возвращает соответствующий пункт палитры в «Нет».
- Панель **«Связи»** (справа снизу) — **контекстная, как ПКМ «Показать связи»**: список типов связей
  выбранного узла из полного набора `relations` (включая ещё не показанные на графе), подпись
  «Название (Тип A → Тип B)», чекбокс = **«тип раскрыт полностью»** (видны все инцидентные связи этого
  типа). Частично раскрытый тип показывается пустой галочкой — клик **дораскрывает** недостающие связи;
  скрытие — клик по полной галочке или «Отменить все». Переключение идёт тем же механизмом, что ПКМ
  (`expandRelationsAtNode` / `hideRelationsAtNode`). Кнопки **«Выбрать все» / «Отменить все»** — как ПКМ
  «Все типы» вкл/выкл.
- Узлы, потерявшие все видимые связи, скрывает `pruneOrphanVisibleNodes` (корень графа сохраняется).
  Если выбрана связь, а не узел, панель показывает подсказку. Состояние раскрытия типов живёт
  в `AnalyticsView` и не сбрасывается при закрытии панели; «Новый граф» очищает его.
- Повторное включение уже показанных типов **не перекладывает узлы**: координаты кэшируются
  (`layoutCache`); если новых узлов нет, геометрия не меняется. При появлении новых узлов хаб
  сдвигается по оси связи и все возвращаемые узлы раскладываются звездой (issue #134).
- Во встройке палитры нет (`variant="embed"`), выделение работает; контекстное меню прежнее
  (`minimal` — только «Просмотр»).
- Подробности — [issue-116-analyzer-property-palette.md](./issue-116-analyzer-property-palette.md).

## Данные

На формах передаётся **явный список связей** той же сущности, что отображается в таблице (например `GET /api/ar-gaps/:id/relations`), далее родитель строит `nodes`/`edges` через `relationsToGraphData` и при необходимости обогащает подписи через `fetchEntity`.

## Пример

См. `GapForm.vue` (вкладка «Связи»): таблица и граф **40% / 60%**, `variant="embed"`, `graph-height="780px"`, `:show-export-buttons="true"`, `:center-node-id="gapCenterNodeId"`.
