# Встраивание `AnalyzerGraph` (issue #33)

## Назначение

Один компонент `frontend-v3/src/components/AnalyzerGraph.vue` используется в **анализаторе зависимостей** и на **вкладках «Связи»** форм. Режим задаётся пропом **`variant`**.

## Пропсы

| Проп | Описание |
|------|----------|
| `variant` | `'analyzer'` (по умолчанию) — полный UI; `'embed'` — без левой панели и экспорта SVG/PNG, узлы не перетаскиваются. |
| `showToolbar` | Явно показать/скрыть панель (как слева, так и кнопки экспорта). Если не задано: при `embed` — скрыто, иначе — показано. |
| `contextMenu` | `'full'` \| `'minimal'` \| `'off'`. Если не задано: `embed` → `'minimal'` (только «Просмотр»), иначе `'full'`. |
| `graphHeight` | Высота области графа. Как у основного экрана анализатора: **`780px`**. Без значения у `embed` — ~420px. |
| `showExportButtons` | Кнопки **SVG** / **PNG**. Если не задано — показываются только вместе с полной панелью (`showToolbar`). На формах задайте `true`, чтобы оставить экспорт без левой панели раскладок. |
| `centerNodeId` | `nodeId` центра для первичной раскладки «звезда» при появлении узлов (удобно, когда известен корень, напр. `gap:12`). |

Остальные пропсы (`nodes`, `edges`, `relations`, `relationTypes`, `showCascadeToggle`, …) без изменений.

## Данные

На формах передаётся **явный список связей** той же сущности, что отображается в таблице (например `GET /api/ar-gaps/:id/relations`), далее родитель строит `nodes`/`edges` через `relationsToGraphData` и при необходимости обогащает подписи через `fetchEntity`.

## Пример

См. `GapForm.vue` (вкладка «Связи»): таблица и граф **40% / 60%**, `variant="embed"`, `graph-height="780px"`, `:show-export-buttons="true"`, `:center-node-id="gapCenterNodeId"`.
