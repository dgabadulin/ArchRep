# Функциональные вертикали (справочник владельцев/направлений)

**GitHub:** https://github.com/dgabadulin/ArchRep/issues/123

Справочник `archrep.ar_system_owners` используется как список **функциональных вертикалей**. В UI он называется «Функциональные вертикали» (ранее — «Владельцы (направления)»).

## Поле `Доп.классификация1`

- Колонка БД: `extra_classification1` (`VARCHAR(255)`, nullable).
- В UI — выпадающий список; пустое значение допускается.
- Список значений:

| Доп.классификация1 |
|---|
| Производство и операции |
| Финансы и экономика |
| Персонал (HR) |
| Продажи и клиентский сервис |
| Закупки и логистика |
| Технический блок и инжиниринг |
| ИТ |
| Безопасность |
| Административно-правовой блок |
| Управляющая компания |

## Заполнение существующих записей

Миграция `20261120140000_owner_extra_classification1`:

1. Пытается сопоставить `name` с точным названием из списка.
2. Затем применяет best-effort правила по ключевым словам (производство, финансы, персонал, продажи, закупки, технический, ИТ, безопасность, административно-правовой, управляющая компания).
3. Если название не распознано, поле остаётся `NULL` — классификацию можно выбрать вручную.

Уже заполненное значение миграция не перезаписывает.

## API и UI

- `GET /api/owners` — возвращает `extra_classification1`.
- `POST/PUT /api/owners` — принимает `extra_classification1`.
- UI: «Справочники → Функциональные вертикали», колонка и select в форме.
