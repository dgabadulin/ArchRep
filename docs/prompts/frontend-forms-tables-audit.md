# Промпт: Аудит табличных экранов и форм редактирования (frontend-v3)

## Контекст

- **Проект/репозиторий:** архитектурный репозиторий, фронтенд `frontend-v3` (Vue 3).
- **Файлы/схемы:** `frontend-v3/src/views/*List.vue`, `Technologies.vue`, `Principles.vue`, `SettingsParametersView.vue`, `ReferencesV2.vue`, `ReferencesTogaf.vue`, `frontend-v3/src/views/*Form.vue`, `frontend-v3/src/components/TableToolbar.vue`, `frontend-v3/src/utils/tableColumns.js`.
- **Ограничения:** аналитический запрос без обязательных правок кода; при рефакторинге — не ломать маршруты и API без согласования.

## Цель

Получить структурированный отчёт по всем табличным экранным формам и формам редактирования: зафиксировать стилистические, функциональные и поведенческие различия (паттерны разметки, тулбары, модалки vs отдельные маршруты, API-слой, сортировка/колонки/Excel, блоки кнопок, `useUnsavedGuard` и т.д.) и краткие рекомендации по выравниванию.

## Промпт для ИИ (скопировать в чат)

```
Обнаружил что некоторые табличные формы и формы редактирования отличаются стилистически, функционально и поведенчески. проведи анализ всех табличных экранных форм и ворм редактирования и сделай отчет
```

## Формат ответа

- Структурированный отчёт в Markdown: перечень охваченных экранов, группировка по паттернам, таблицы расхождений, выводы и рекомендации (без лишнего кода, при необходимости — ссылки на пути файлов в бэктиках).

## Критерии готовности

- Учтены все списки в `frontend-v3/src/views` с таблицами и отдельные формы `*Form.vue`, а также экраны с таблицей + модалкой (принципы, параметры, справочники).
- Явно разделены: стилистика (разметка, классы, дублирование стилей), функциональность (Excel, удаление, сортировка, выбор колонок, вкладки) и поведение (поиск, guard несохранённого, состояние saving).
- Есть краткий итог и практичные направления унификации.
