# Промпт: тема UI «по мотивам portal» для frontend-v3

## Контекст

- **Проект/репозиторий:** архитектурный репозиторий, фронт `frontend-v3` (Vue 3).
- **Файлы:** эталон визуала — локальный HTML-макет `portal.html` (React + inline-стили); в приложении — `src/styles/theme.css`, `LayoutV3.vue`, `TableToolbar.vue`, `Breadcrumbs.vue`, экраны в `src/views/*.vue`, компоненты в `src/components/*.vue`.
- **Ограничения:** не копировать 1:1 чужой бренд; перенос «по мотивам» (палитра, типографика, карточки, меню). Не ломать разметку и поведение форм/таблиц.

## Цель

- Единая тема: CSS-переменные + общие классы (кнопки, карточки, таблицы, поля форм, вкладки, ссылки).
- Сайдбар и фон приложения в духе portal (нейтральный фон, белый сайдбар, акцент teal).
- Убрать дублирование однотипных `scoped`-стилей в экранах, опираясь на глобальную тему.

## Промпт для ИИ (скопировать в чат)

```
Сохрани текущую формулировку в prompt реализуй весь реалистичный план. По поводу твоего вопроса: Нужен четкий список: «копируем 1:1» или «по мотивам portal». Ответ: по мотивам portal
```

## Формат ответа

- Файл промпта в `docs/prompts/portal-inspired-theme-rollout.md`.
- Изменения во фронте: `theme.css`, подключение в `main.js`, шрифт Inter в `index.html`, обновление shell-компонентов и поэтапная зачистка дублей в `.vue`.

## Критерии готовности

- [x] В репозитории есть `frontend-v3/src/styles/theme.css` с токенами и общими UI-классами.
- [x] `main.js` подключает тему до остальных стилей приложения.
- [x] `LayoutV3` и `TableToolbar`/`Breadcrumbs` используют переменные темы.
- [x] Основные списки и формы не дублируют блоки `.btn-*` / `.card` / базовой `.table` там, где достаточно глобальных правил.
- [ ] Сборка фронта проходит без ошибок (`npm run build` в `frontend-v3`) — проверить локально: в среде агента `npm` недоступен в PATH.
