# Промпт: Cloud Agent vs Desktop Cursor

## Контекст

- **Проект/репозиторий:** архитектурный репозиторий ArchRep.
- **Сценарий:** нужно быстро понять, какой интерфейс Cursor выбрать для конкретной задачи.
- **Ограничения:** ответ должен быть практическим, коротким и ориентированным на повседневную работу.

## Цель

Получить удобный чек-лист, который помогает выбрать между Cloud Agent и Desktop Cursor в зависимости от типа задачи: автономная автоматизация, локальная отладка, работа с сервисами, подготовка PR и т.д.

## Промпт для ИИ (скопировать в чат)

```
Сравни Cloud Agent и Desktop Cursor в формате практического чек-листа.

Что хочу получить:
- когда лучше использовать Cloud Agent;
- когда лучше использовать Desktop Cursor;
- когда лучше комбинировать оба варианта;
- короткое правило выбора в 1-2 строках.

Сделай ответ прикладным, без маркетинговых формулировок.
Формат:
1. Блок "Когда лучше Cloud Agent" с чекбоксами.
2. Блок "Когда лучше Desktop Cursor" с чекбоксами.
3. Блок "Гибридный сценарий".
4. Блок "Быстрое правило выбора".
```

## Формат ответа

- Короткий текст на русском языке.
- 4 блока с заголовками и чекбоксами.
- Без лишней теории, с упором на принятие решения.

## Критерии готовности

- Есть отдельный список для Cloud Agent.
- Есть отдельный список для Desktop Cursor.
- Есть рекомендации по гибридному использованию.
- Есть краткое правило выбора для повседневной работы.
- Ответ можно переиспользовать как шаблонный запрос без доработки.
