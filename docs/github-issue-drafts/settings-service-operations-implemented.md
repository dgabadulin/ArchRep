## Цель

Вынести массовые административные операции в отдельный раздел настроек; на первом этапе — пересборка проекций интеграционных потоков в метамодели.

## Сделано

- Меню **Настройки → Сервисные операции** (`/settings/service-operations`).
- Страница `SettingsServiceOperationsView.vue`: секция «Метамодель», карточка с описанием и кнопкой **Запустить**; `confirm` перед вызовом API; сообщение об успехе/ошибке.
- API без изменений: `POST /api/togaf/metamodel/rebuild-integration-flow-projections`.
- Кнопка пересборки **убрана** со списка связей метамодели (`MetamodelRelationsList.vue`).
- Подсказка в форме связи ведёт на сервисные операции (`MetamodelRelationForm.vue`).
- Маршрут, меню, иконка `wrench`, крошки, описание плитки на главной (`HomeView`).
