## Цель

Добавить Excel-подобную фильтрацию по колонкам в табличных формах ИСАР (MVP на клиенте), не заменяя глобальный поиск.

**Пилот:** Каталог ИС (`SystemsList.vue`).

## Принятые решения

- Клиентская фильтрация по уже загруженным строкам (после глобального `search` с API)
- Текстовые колонки: условие **«содержит»** (без списка уникальных значений)
- Сохранение состояния фильтров в **cookie** (как «Вид» и сортировка)
- **Excel-экспорт** — только отфильтрованные строки и видимые колонки
- Пилот на **Каталоге ИС**, затем раскатка на остальные реестры

## Спека

Подробности: `docs/table-column-filters-spec.md`

## Scope пилота

- Composable `useTableColumnFilters`, меню фильтра на заголовках колонок
- Типы: `text` (содержит), `enum` (чекбоксы distinct), `bool`
- Интеграция в `SystemsList.vue`, клиентский экспорт xlsx
- Backend / БД не меняются

## Критерии готовности

См. чеклист в спеке (фильтры, cookie, AND по колонкам, экспорт, регрессия «Вид»/сортировка/RBAC).
