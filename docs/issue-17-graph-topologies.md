# Топологии графа анализа зависимостей

Эталонные варианты топологий заданы в `temp/топологии.jpg`. Ниже — соответствие с реализацией в компоненте Анализатор (v-network-graph).

## 1. Шинная (Bus)

- **Эталон:** центральная горизонтальная линия (шина), узлы ответвляются сверху/снизу.
- **В компоненте:** отдельная раскладка не реализована. Можно добавить: один «виртуальный» путь по горизонтали, узлы — над/под ним с чередованием.

## 2. Кольцевая (Ring)

- **Эталон:** узлы по окружности, каждый связан с двумя соседями.
- **В компоненте:** реализовано. Контекстное меню → «Раскладка: Кольцо» → `applyLayout('ring')`. Узлы размещаются по окружности (радиус 200).

## 3. Звездообразная (Star)

- **Эталон:** один центральный узел, остальные только с ним.
- **В компоненте:** реализовано.
  - При построении графа по **одному** выбранному объекту автоматически применяется звезда: выбранный узел в центре, соседи по окружности (радиус 200, первый периферийный сверху).
  - Контекстное меню → «Раскладка: Звезда» → центр по выбранной вершине (если вызвано с узла) или по первому в списке.
  - При «Добавить связи» новые узлы раскладываются звездой вокруг раскрываемой вершины (с учётом зазора от остальных узлов).

## 4. Расширенная звезда (Extended star)

- **Эталон:** центр → промежуточные узлы → у каждого по несколько периферийных.
- **В компоненте:** реализовано. Контекстное меню → «Раскладка: Расширенная звезда». Центр — выбранный узел (или первый), уровень 1 — соседи центра по рёбрам на окружности R=200, уровень 2 — соседи уровня 1 (кроме центра и уровня 1) размещаются в секторах вокруг соответствующего узла уровня 1 на окружности R=380. Остальные узлы — на внешней окружности.

## 5. Иерархическая (Hierarchical)

- **Эталон:** дерево — корень сверху, уровни вниз.
- **В компоненте:** реализовано. Контекстное меню → «Раскладка: Иерархия». Корень — выбранный узел (или первый), обход в ширину (BFS) по рёбрам задаёт уровни; каждый уровень размещается горизонтально с шагом 100 px, уровни по вертикали с шагом 120 px. Недостижимые узлы выносятся на следующий уровень.

## 6. Полносвязная (Fully connected)

- **Эталон:** все узлы соединены со всеми (пентагон + диагонали).
- **В компоненте:** реализовано. Контекстное меню → «Раскладка: Полносвязная». Узлы размещаются по одной окружности (как в кольце), что удобно для графов «все со всеми».

---

## Масштабирование

- После `fitToContents()` (построение графа, добавление уровня) действует ограничение: **минимальный размер viewBox 500 px** по ширине и высоте. При меньшем размере viewBox (слишком сильное приближение) он расширяется с сохранением центра, чтобы граф не выглядел «гигантским» при малом числе узлов.
- Правило «только уменьшать масштаб» при программном fit сохранено: если после fit масштаб стал больше прежнего, восстанавливается прежний viewBox.

## Текущее меню раскладок

- **Звезда** — центр по выбранному узлу или первому, остальные по окружности.
- **Кольцо** — все узлы по одной окружности.
- **Расширенная звезда** — центр, уровень 1 на окружности, уровень 2 в секторах вокруг уровня 1.
- **Иерархия** — дерево от выбранного корня (BFS), уровни сверху вниз.
- **Полносвязная** — все узлы по окружности (как кольцо).
- **Сетка** — узлы в сетке (по умолчанию при нескольких выбранных объектах).

Файлы экспорта в `temp/` (graph_start.svg, graph_start2.svg) использованы для анализа проблем масштаба и геометрии звезды; правки внесены в компонент.
