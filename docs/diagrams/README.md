# Схемы метамодели ИСАР (версии)

История схем. Каждая версия — **отдельный файл**, прежние не редактируются.

| Версия | Снимок | Что вошло |
|---|---|---|
| `Метамодель ИСАР 2.0.pptx` | 19.11.2026 | базовый снимок: 17 типов сущностей, 39 типов связей |
| `Метамодель ИСАР 2.1.pptx` | 22.11.2026 | связь `organization_unit → system` «Владеет» (`owns_system`, issue #126) — 40 типов связей |

## Правило версионирования

- добавлена **связь** → минор: `2.0 → 2.1`;
- добавлена **сущность** (тип сущности) → мажор: `2.1 → 3.0`.

Правило: `.clinerules` §10, `.cursor/rules/metamodel-version.mdc`.

## Генерация

```bash
npm run build:metamodel -- 2.1
```

Скрипт: `scripts/build-metamodel-slide.js` — собирает PPTX (OOXML + ZIP, без внешних зависимостей)
и проверяет раскладку: номера связей не на карточках и не пересекаются, линии не проходят сквозь
сущности, **концы линий лежат на границах карточек «от» и «к» (нет связей «в никуда»)**,
**линии и номера не заходят в панель легенды, легенда не перекрывает карточки**,
**сегменты разных связей не идут по одной прямой (нет наложений), номер не лежит на чужой линии,
все сегменты ортогональны**, каждый тип связи изображён ровно один раз.
При проблеме сборка прерывается с перечнем ошибок. Данные схемы (сущности, связи, маршруты) — в этом же скрипте.
