### Системы, задействованные в реализации решения

В данном разделе указываются все системы, задействованные в реализации архитектурного заключения.

#### Правила заполнения полей

| Поле                                                  | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **№ п/п**                                             | Заполняется автоматически по мере добавления строк                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Наименование системы / модуля**                     | Указывается название системы, функционал которой изменяется в ходе реализации данного архитектурного заключения (или система, которая вводится / выводится в эксплуатацию). Выбирается из справочника.                                                                                                                                                                                                                                                   |
| **Статус системы в рамках архитектурного заключения** | Указывается одно из следующих значений: 1) **Создается новая** — в случае создания новой системы / модуля; 2) **Модифицируется** — в случае изменения функциональности существующей системы / модуля; 3) **Выводится из эксплуатации** — в случае прекращения использования системы / модуля; 4) **Применяется** — система используется без изменений. 5) **Создается в другом решении** - система пока не существует, но создается не в текущем проекте |
| **Функции**                                           | Приводится перечень функций, задействованных в реализации решения (отглагольная форма существительных - Формирование отчета..., Управление пользователями, и т.п.)                                                                                                                                                                                                                                                                                       |
